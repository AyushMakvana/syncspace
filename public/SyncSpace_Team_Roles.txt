Role Title : Frontend Developer & UI/UX Specialist

----------------------------------------------------------------------------------------
MEMBER 3: CLOUD & DATABASE ENGINEER
----------------------------------------------------------------------------------------
Role Title : Backend & Database Infrastructure Lead
Key Responsibilities:
  • Implementing Firebase Authentication (Google 1-click OAuth Popup & Email/Password).
  • Designing Cloud Firestore NoSQL schema structures (`rooms/{roomId}` and `codes/{code}`).
  • Configuring cloud security rules, database indexes, and serverless authentication state.
  • Managing persistent user profile data and room code lookup registries.

----------------------------------------------------------------------------------------
MEMBER 4: REAL-TIME ENGINE & MEDIA SPECIALIST
----------------------------------------------------------------------------------------
Role Title : Real-Time Synchronization & Media Engineer
Key Responsibilities:
  • Developing the sub-100ms dual-engine live chat system (BroadcastChannel + Firestore).
  • Integrating YouTube Data API v3 for video search, playlist loading, and metadata extraction.
  • Building global video player state synchronization (synchronized play, pause, timestamp scrubbing).
  • Implementing WebRTC and PeerJS infrastructure for live camera and microphone video streams.

----------------------------------------------------------------------------------------
MEMBER 5: QA, TESTING & DEVOPS ENGINEER
----------------------------------------------------------------------------------------
Role Title : Quality Assurance, Performance & DevOps Lead
Key Responsibilities:
  • Conducting cross-browser compatibility testing (Chrome, Edge, Firefox, Safari & Mobile).
  • Optimizing memory cache performance (`memoryLocalCache()`) to eliminate database lock issues.
  • Managing Git version control repositories, branching strategies, and codebase maintenance.
  • Managing web deployment hosting (Vercel / Firebase) and compiling technical documentation.
